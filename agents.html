Claude Code

Anthropic 官方代码 Agent，最懂约束的编码伙伴。擅长 SOP 严守和复杂任务拆解。
MCP 生态SOP 严守多模态
  1. 安装 Node.js（推荐 v18+）
  2. 运行 npm install -g @anthropic-ai/claude-code
  3. 配置 ANTHROPIC_API_KEY
  4. 在项目目录运行 claude
约束遵从 ★★★★★代码能力 ★★★★☆

OpenAI Codex

GPT 系列代码专用 Agent，SWE-bench 标杆。生态系统最完善，终端执行能力强。
SWE-bench 最高生态最大终端执行
  1. 安装 OpenAI CLI（pip install openai）
  2. 配置 OPENAI_API_KEY
  3. 通过 API 或 ChatGPT 界面调用
  4. 集成到 IDE 或 CI/CD 流程
代码能力 ★★★★★生态完善 ★★★★★

Cursor

基于 VS Code 的代码编辑器，内置 AI Agent。适合日常开发，零配置上手。
零配置IDE 集成日常开发
  1. 访问 cursor.com 下载安装包
  2. 安装后直接打开项目
  3. 配置 API Key（可选）
  4. 使用 Cmd/Ctrl+K 或 Cmd/Ctrl+L 调用 AI
上手难度 ★日常开发 ★★★★★

Claude Code

代码开发智能体 · 铸造级约束遵从
1. 安装 CLI：brew install claude-code
2. 配置 MCP：claude mcp init --template code-review
3. 初始化项目：claude code init --project ./
4. 启动开发：claude code start --watch
🧠 代码审查 🔧 自动修复 📝 文档生成

Codex

全能终端智能体 · SWE-bench 最高分
1. 安装 SDK：pip install openai-codex
2. 设置 API Key：export OPENAI_API_KEY=sk-xxx
3. 启动终端：codex terminal --autonomous
4. 赋予任务：自然语言描述需求即可执行
🖥️ 终端执行 📂 文件操作 🔍 代码搜索

Cursor

IDE 原生智能体 · 编辑器内全流程

2. 登录并选择模型后端（GPT-5.4 / Claude Sonnet 4.6）
3. 用 Cmd+K 唤起 Composer 智能体模式
4. 自然语言编写代码、重构、调试
